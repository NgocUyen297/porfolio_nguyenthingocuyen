The Co.op Food App is an internal employee attendance management system for retail stores. It enables staff to check in and check out at store locations, records attendance history, and verifies GPS coordinates during check-in. Administrators can view detailed reports by store and by individual employee.
Vai trò của bản thân: 
﻿﻿I developed the entire mobile Ul and actively participated in discussing and proposing business solutions for the project.
﻿﻿Implemented GPS-based attendance verification system for retail employees.
﻿﻿Developed real-time check-in/check-out workflows with location validation.
﻿﻿Participated in business analysis and proposed operational improvements for attendance tracking.
Technologies Used
Mobile Application: React Native
Push Notification Service: OneSignal for real-time server notifications and attendance updates
Backend System: .NET Framework Web API
GPS & Location Services for attendance validation
RESTful API integration between mobile app and backend system
Main Features
Employee check-in/check-out system using real-time GPS location verification
Validate whether employees are within the allowed store check-in area before attendance submission
Store and manage attendance history, including check-in/check-out timestamps and locations
Real-time attendance workflow synchronization between mobile app and server
Push notifications for attendance-related updates and announcements
Admin dashboard/reporting features:
View attendance reports by store
Track daily employee check-in/check-out statistics
Monitor the number of employees present for each store and date
Business-oriented attendance management designed for retail store operations

Caching & Performance Optimization: Redis

Main Features
Social networking platform with user interaction and community engagement
Real-time messaging and communication features
News and entertainment system including articles, videos, and music content

Multi-service super app experience within a single platform
